# Kelly Cao Portfolio

I am building a professional portfolio website for a Biomedical Enginee. We will be building this section by section. Please use a Corporate and Professional aesthetic with a cool gray and muted blue palette (slate-50, slate-700, blue-600). The global typography must be the ‘Inter’ font. Ensure the page has smooth scrolling.

Please buld the first two section the header and hero section, and let me know when you are ready for the ‘About Me’ section.

Build a sticky top navigation bar using a clean, minimal design (bg-slate-50 or transparent with a blur effect). On the left, add a simple text logo: ‘Kelly Cao’. On the right, add the following navigation links: ‘About’, ‘Professional Experiences’, ‘Projects’, ‘Skills’, ‘Certifications’, ‘Coursework’, ‘Contact me’. Ensure the navigation collapses into a hamburger menu for mobile devices.

Build the hero section. Use a cool gray and muted blue palette. Add a small overline text that says ‘Portfolio of Kelly Cao’. The main h1 headline must be exactly: ‘Biomedical Engineer | Design, Testing, and Compliance’. Underneath, add sub-headline text: ‘Leveraging a BS and MS in Biomedical Engineering to support product development. Passionate about regulatory compliance, continuous improvement, and creating innovative solutions that have meaningful impacts.’ Below the sub-headline, add a primary CTA button that says ‘Download Resume’ with a subtle hover lift effect.
